Pencil, pointer, keyboard

Use the input that fits the moment.

Pencil remains a pen. A connected iPad trackpad or mouse remains a mouse. Keyboard input stays separate from both.

01

Apple Pencil

Draw directly into the selected Windows monitor. NFiDB forwards the primary tip, pressure, tilt, and coalesced samples as native Windows pen input.

In the drawing app, select its Windows Ink or pointer-input path when available.
02

Trackpad or mouse

Move the Windows cursor, click, secondary-click, drag, and scroll horizontally or vertically. Pointer coordinates follow the video fit mode.

Keep Safari in the foreground so iPadOS delivers pointer events to the page.
03

Hardware keyboard

With the Keyboard panel closed, key-down and key-up events go straight to Windows. Held modifiers and drawing-app shortcuts work normally.

Open Keyboard when you want layout-independent text or the on-screen special keys.

The iPad toolbar

Everything in the top strip.

The toolbar hides to leave the canvas clear. Tap the small tab at the top edge to bring it back.

FitShows the complete monitor with letterboxing when needed.
FillFills the iPad screen and crops the monitor edges.
1:1Centers the encoded video at its native pixel size.
TouchForwards finger contact as native Windows touch. This pauses three-finger gestures.
GesturesEnables or disables the three-finger Windows commands.
KeyboardOpens text entry plus Esc, Tab, Backspace, Enter, app, Task View, and minimize buttons.
StatsShows video, bandwidth, latency, loss, frame timing, pressure, tilt, and input integrity.
FullscreenRequests browser fullscreen. Add to Home Screen gives Safari the least chrome.
×Disconnects, releases held input, and returns to pairing.

Quick fixes

Most problems are pairing or network state.

NFiDB does not use a cloud relay. Both devices must be able to reach each other on the same trusted LAN.

No page or connection

Use a normal private Wi-Fi network, not guest Wi-Fi. Allow NFiDB through Windows Firewall on Private networks only.

Expired PIN or stale QR error

Open Session on Windows and choose Reset PIN + QR, then reload Safari and use the new code.

Connected but no picture

NFiDB now requests fresh video keyframes until Safari presents a frame. Give it a few seconds; if it still does not appear, reload the page and pair again.

No pressure in a drawing app

Enable the app's Windows Ink/pointer input option. Run pointer-sink.exe --self-test to verify the native pen path independently.

Need measurements

Open Stats on the iPad or Diagnostics on Windows. Reports stay local unless you export them.
