Portable by design

Unzip, run, pair.

Nothing needs to be installed on your iPad. NFiDB serves the drawing client directly to Safari over your private local network.

  1. 1
    Download the ZIPOpen GitHub Releases and choose the newest NFiDB-windows-x64.zip. A SHA-256 checksum is provided beside it.
  2. 2
    Extract and runUnzip the package, start nfidb.exe, and allow Private-network access if Windows asks.
  3. 3
    Pair your iPadOpen the local address in iPad Safari, enter the six-digit PIN or scan the QR code, and draw.

Before you run it

Windows may warn you.

NFiDB is currently an unsigned prerelease, so Windows may show a security prompt. Download only from the official GitHub releases page and compare the published SHA-256 checksum if you want to verify the package.
