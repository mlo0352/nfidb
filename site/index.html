Technical details

Under the hood.

The short version: your Windows PC does the work and your iPad connects directly to it.

01

Local video

NFiDB serves the iPad page from the Windows host and sends H.264 video over a direct WebRTC connection. No cloud relay is involved.

02

Native pen input

Safari Pointer Events carry pressure and tilt back to Windows as native PT_PEN input. Predicted events remain visual-only.

03

Files and diagnostics

Explicit file queues move data in either direction. Live stats cover latency, bandwidth, input integrity, and transfer results without sending data elsewhere.
